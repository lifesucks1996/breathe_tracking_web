Detailed Description

Gestión de autenticación, recuperación de roles y redirección de usuarios.

Este módulo maneja todo el flujo de inicio de sesión:

  1. Autenticación contra Firebase Authentication.
  2. Consulta adicional a Firestore para recuperar el rol del usuario (Admin vs Usuario).
  3. Lógica de UI para mostrar/ocultar contraseñas.
  4. Redirección condicional basada en el rol recuperado.

◆ fetchUserProfile()

async function fetchUserProfile ( userId )

Recupera el perfil extendido del usuario desde Firestore para determinar su rol. userId: string -> fetchUserProfile() -> Promise<Object>.

Accede a la colección "Usuarios" utilizando el UID proporcionado por Authentication. Extrae el campo 'Id_rol' para normalizarlo y devolverlo junto con el resto de datos. Si el documento no existe, asigna un rol por defecto ('usuario') para evitar bloqueos.

Note
Es crucial para la seguridad de la navegación, ya que el Auth de Firebase por sí solo no almacena roles personalizados en este esquema.
Parameters
userIdEl identificador único (UID) del usuario autenticado.
Returns
Promesa que resuelve en un Objeto con los datos del usuario y la propiedad 'rol'.
