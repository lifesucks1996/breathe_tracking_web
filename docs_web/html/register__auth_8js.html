Detailed Description

Módulo de registro de nuevos usuarios en la plataforma.

Gestiona todo el proceso de alta de usuario:

  1. Validación estricta de formularios (formato email, coincidencia de contraseñas, complejidad).
  2. Creación de credenciales en Firebase Authentication.
  3. Creación del perfil de usuario extendido en Firestore Database.
  4. Manejo de errores comunes (email duplicado, red, etc.).

function esEmailValido ( email )

Valida el formato de un correo electrónico mediante Expresiones Regulares (Regex). email:string -> esEmailValido() -> boolean.

Comprueba si la cadena de entrada cumple con el patrón estándar de un email: caracteres + @ + caracteres + . + extensión.

  • Parameters

    Returns
    true si el formato es correcto, false en caso contrario.
