Detailed Description

Gestión de estaciones oficiales de calidad del aire.

Este script se conecta a la API pública de WAQI (World Air Quality Index) para obtener datos de estaciones oficiales cercanas y las dibuja en el mapa. Incluye:

  • Detección de movimiento del mapa para recargar estaciones.
  • Renderizado de iconos personalizados con el color del AQI.
  • Popups interactivos que piden datos detallados bajo demanda.

@requires Leaflet.js - Para dibujar marcadores y popups.

async function cargarEstaciones ( mapa )

Consulta la API de WAQI para obtener estaciones dentro de los límites visibles.

Obtiene los bounds (Norte, Sur, Este, Oeste) del mapa y construye la URL de consulta. Si la respuesta es exitosa, llama a dibujarEstacionesComoIconos.

{L.Map}mapa - Instancia del mapa para obtener los límites (bounds). @async

◆ dibujarEstacionesComoIconos()

function dibujarEstacionesComoIconos ( estaciones )

Renderiza las estaciones recibidas como iconos en el mapa.

  1. Limpia los marcadores antiguos de capaEstaciones.
  2. Itera sobre cada estación recibida.
  3. Crea un L.divIcon personalizado con el color correspondiente al AQI.
  4. Añade un tooltip y un evento click para ver detalles.
Parameters
{Array<Object>}estaciones - Lista de estaciones devuelta por la API.

◆ inicializarEstacionesOficiales()

function inicializarEstacionesOficiales ( mapa )

Inicializa el sistema de estaciones oficiales en el mapa proporcionado.

  1. Crea la capa capaEstaciones y la añade al mapa.
  2. Carga las estaciones visibles inicialmente.
  3. Configura un listener moveend para recargar estaciones al mover el mapa (con debounce de 1s).
Parameters
{L.Map}mapa - Instancia del mapa Leaflet donde se pintarán las estaciones.

◆ obtenerColorAQI()

function obtenerColorAQI ( aqi )

Devuelve un color hexadecimal según el nivel de AQI.

  • 0-50: Verde (Bueno)
  • 51-100: Amarillo (Moderado)
  • 101-150: Naranja (Insalubre para grupos sensibles)
  • 151-200: Rojo (Insalubre)
  • 201-300: Morado (Muy insalubre)
  • >300: Granate (Peligroso)
Parameters
{number}aqi - Índice de Calidad del Aire.
Returns
{string} Color en formato Hex.
