\doxysubsection{Detailed Description}
Módulo de registro de nuevos usuarios en la plataforma. 

Gestiona todo el proceso de alta de usuario:\+
\begin{DoxyEnumerate}
\item Validación estricta de formularios (formato email, coincidencia de contraseñas, complejidad).
\item Creación de credenciales en Firebase Authentication.
\item Creación del perfil de usuario extendido en Firestore Database.
\item Manejo de errores comunes (email duplicado, red, etc.). 
\end{DoxyEnumerate}
