\doxysubsection{Detailed Description}
Panel de Administración:\+ Gestión de sensores, heatmap congelado, paginación y gestión de incidencias. 

Este módulo implementa las siguientes funcionalidades:\+
\begin{DoxyItemize}
\item Carga dinámica de sensores desde \doxylink{admin__sensors__data_8js}{admin\+\_\+sensors\+\_\+data.\+js}
\item Renderizado con sistema de paginación (20 sensores por página)
\item Mapa de calor congelado sincronizado con datos de contaminación
\item Selección de gases (O₃, NO₂, CO, SO₂, CO₂)
\item Filtros avanzados:\+ Estado (Activo/\+\+Inactivo/\+\+Incidencia) y Ordenación por tiempo.
\item Gestión visual de capas (Z-\/\+Index) para evitar saturación en el mapa.
\end{DoxyItemize}
