\doxysubsection{Detailed Description}
Script de backend (PHP) para la verificación de cuentas vía correo electrónico. 

Este script actúa como el \textquotesingle{}endpoint\textquotesingle{} al que accede el usuario al hacer clic en el enlace de verificación recibido por email.
\begin{DoxyItemize}
\item Flujo principal:\+
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item Conexión segura con Firebase Firestore usando credenciales de servicio.
\item Decodificación de parámetros URL (Email y Token).
\item Validación de integridad (Token BBDD vs Token URL).
\item Verificación de caducidad (Token expirado).
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Si caducado:\+ Genera uno nuevo, actualiza BBDD y llama a la API de correo para reenviar.
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item Confirmación de éxito:\+ Actualiza el estado del usuario a \textquotesingle{}verificado\textquotesingle{}.
\item Renderizado de respuesta visual HTML. 
\end{DoxyEnumerate}
