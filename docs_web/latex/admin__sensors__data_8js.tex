\doxysubsection{Detailed Description}
Generación de datos simulados (Mock Data) para el Frontend. 

Este archivo simula la estructura de datos que normalmente vendría de Firebase. Se utiliza para desarrollo y pruebas de carga en la interfaz (UI).
\begin{DoxyItemize}
\item Contiene:\+
\item 7 Sensores "{}\+Reales"{} estáticos.
\item 200 Sensores simulados generados algorítmicamente.
\item Lógica para simular estados (Conectado, Alerta, Desconectado) y fechas pasadas.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Este script replica el comportamiento del script de Python de carga masiva. 
\end{DoxyNote}
