\doxysubsection{Detailed Description}
Interfaz visual del mapa de usuarios:\+ Heatmaps, Pines y Reportes PDF. 

Gestiona la experiencia principal del usuario en la pantalla de mapa:\+
\begin{DoxyEnumerate}
\item Inicializa el mapa Leaflet centrado en Gandía.
\item Carga datos de Firebase y renderiza el mapa de calor (Heatmap).
\item Permite añadir "{}\+Pines"{} (marcadores personalizados) en el mapa.
\item Muestra detalles de contaminación interpolados en la posición del pin.
\item Genera informes PDF premium usando js\+PDF.
\item Integra las estaciones oficiales de WAQI ({\ttfamily \doxylink{official__stations_8js}{official\+\_\+stations.\+js}}).
\end{DoxyEnumerate}
