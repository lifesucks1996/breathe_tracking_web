\doxysubsection{Detailed Description}
Gestión de datos de mapas, conexión a Firebase y cálculos matemáticos. 

Este archivo actúa como la capa de datos (Model) para el mapa de usuarios. Sus responsabilidades principales son:\+
\begin{DoxyEnumerate}
\item Conectar con Firebase Firestore para descargar mapas diarios de contaminantes.
\item Procesar los datos crudos y convertirlos en puntos visuales (Heatmap) con intensidad 0-\/1.
\item Realizar cálculos matemáticos (Interpolación IDW) para estimar la contaminación en cualquier punto donde el usuario haga clic, basándose en los sensores cercanos.
\item Gestionar la caché de datos para evitar descargas innecesarias.
\end{DoxyEnumerate}
