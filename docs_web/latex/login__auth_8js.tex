\doxysubsection{Detailed Description}
Gestión de autenticación, recuperación de roles y redirección de usuarios. 

Este módulo maneja todo el flujo de inicio de sesión:\+
\begin{DoxyEnumerate}
\item Autenticación contra Firebase Authentication.
\item Consulta adicional a Firestore para recuperar el rol del usuario (Admin vs Usuario).
\item Lógica de UI para mostrar/\+ocultar contraseñas.
\item Redirección condicional basada en el rol recuperado. 
\end{DoxyEnumerate}
