\doxysubsection{Detailed Description}
Gestión de estaciones oficiales de calidad del aire. 

Este script se conecta a la API pública de WAQI (World Air Quality Index) para obtener datos de estaciones oficiales cercanas y las dibuja en el mapa. Incluye:\+
\begin{DoxyItemize}
\item Detección de movimiento del mapa para recargar estaciones.
\item Renderizado de iconos personalizados con el color del AQI.
\item Popups interactivos que piden datos detallados bajo demanda.
\end{DoxyItemize}

@requires Leaflet.\+js -\/ Para dibujar marcadores y popups. \begin{DoxyVersion}{Version}
1.\+2 
\end{DoxyVersion}
\begin{DoxyAuthor}{Author}
Breathe Tracking Team 
\end{DoxyAuthor}
