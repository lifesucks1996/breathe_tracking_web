\doxysubsection{Detailed Description}
Gestor de sesión de usuario y manipulación de datos de perfil (CRUD). 

Este script actúa como el controlador principal de la página de perfil. Sus responsabilidades incluyen:\+
\begin{DoxyEnumerate}
\item Escuchar cambios en la autenticación de Firebase (Login/\+\+Logout).
\item Recuperar datos del usuario desde Firestore (soportando búsqueda por UID o Email).
\item Renderizar la información en el DOM.
\item Gestionar el formulario de edición y guardar los cambios en la base de datos. 
\end{DoxyEnumerate}
