## 🔧 Personalización

### Para cambiar colores:
1. Abre `src/css/faq.css`
2. Busca los valores de color (ej: `#667eea`, `#764ba2`)
3. Reemplaza con tus colores

### Para agregar más preguntas:
1. Abre `src/faq.html`
2. Encuentra la sección deseada
3. Copia un `<div class="faq-item">` existente
4. Edita el contenido

### Para modificar el texto del botón:
1. Abre `src/index.html`
2. Busca `class="btn-faq"`
3. Edita el texto dentro del botón
